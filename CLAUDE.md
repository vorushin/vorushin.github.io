# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Build & Development Commands

```bash
bundle install              # Install Ruby dependencies
bundle exec jekyll serve    # Local dev server (http://localhost:4000)
bundle exec jekyll build    # Production build (output: _site/)
```

Requires Ruby 3.3+ and Bundler. CI uses `bundle exec jekyll build --baseurl ""` with `JEKYLL_ENV=production`.

## Architecture

Jekyll 4.3 blog hosted on GitHub Pages. Deploys automatically on push to `master` via `.github/workflows/jekyll.yml`.

### Bilingual Post System

- **English posts** (primary, shown on homepage `/index.html`): use `layout: post-en`, set `lang: en`
- **Russian posts** (legacy archive at `/ru/`): use `layout: post` (default via `_config.yml`)
- Templates filter by `lang` field: `site.posts | where: "lang", "en"`
- Date formats differ: English `%B %d, %Y`, Russian `%d.%m.%Y`
- Use `published: false` in front matter for drafts
- Use `hidden: true` to publish a post accessible via direct link but hidden from the homepage

### Interactive Canvas Visualizations

`_includes/` contains self-contained HTML+JS+CSS canvas visualizations (e.g., `all-gather-ring.html`, `reduce-scatter-ring.html`, `all-to-all-ring.html`, `all-to-all-ring-balanced.html`). Each follows the same pattern:

- IIFE-scoped to avoid conflicts when multiple diagrams appear on one page
- 720x680 logical canvas with DPR=2 for retina
- Element IDs and CSS classes prefixed per diagram (e.g., `allGather`, `reduceScatter`, `allToAllBalanced`)
- Precomputed simulation states, then animated with `requestAnimationFrame`
- Link traffic split into CW/CCW arrays; pills show "A + B" format; headers show CW/CCW breakdown
- Finish stats Y positions must match Hop stats Y positions (both at `CY + 30 * S` and `CY + 50 * S`) to avoid visual jumps
- Play/Pause and Reset controls: buttons use `<span class="btn-icon">` + `<span class="btn-label">` structure; label hides on narrow viewports (<540px) leaving icon-only buttons
- Header text: op name in teal `#0d9488` (22px semibold), state text in warm gray `#78716c` (20px regular)

Include in posts via `{% include diagram-name.html %}`.

### Magic Cats: storybook and game

A trilingual (EN/DE/RU) bedtime story with two faces: a reading page at `/books/magic-cats` and a playable version at `/books/magic-cats/play`. Both read their text from `_data/magic_cats.yml`.

- **Text and beats**: story paragraphs in the YAML contain `" || "` markers that split them into small "beats", aligned across the three languages (62 in total; every paragraph must have the same number of beats in EN, DE and RU). The reading page strips them with `| replace: " || ", " "`; the play page emits them as JSON (`<script id="mcp-story">`). Never edit the wording when moving markers.
- **Language**: `data-lang` on `<html>` + CSS hides other `[lang]` nodes (except the language buttons themselves, `[data-set-lang]`, which carry their own `lang`); priority `?lang=` > `localStorage['magic-cats-lang']` > browser language > `en`. Fonts on both pages: Alegreya (text) and Alice (display), self-hosted: `css/magic-cats-fonts.css` + `fonts/magic-cats/` (Latin and Cyrillic subsets, OFL texts alongside). Both pages declare `color-scheme: dark`.
- **Image filenames in `img/magic-cats/` are a stable contract** (art may be replaced later without layout changes). The reading page serves each PNG painting through `<picture>` with a same-named `.webp` sibling (encoded with Chrome's canvas encoder, about a tenth of the size); regenerate the `.webp` when a PNG changes.
- `ruby _tools/magic_cats_check.rb` checks the one invariant of the story data (equal beat counts per paragraph in all three languages, no empty beats). Typed trailing-slash URLs (`/books/magic-cats/play/`) are sent to the slashless page by a small script in `404.html`.

**The reading page** (`books/magic-cats.html`, `_layouts/book.html`, `css/magic-cats.css`, `js/magic-cats-book.js`): a picture-book layout — two-column spreads with a sticky picture from 992px up, stacked below. `data-scene` on each section (and on "The End", which turns the page to night) drives the page colour journey and one ambient particle layer. Pictures get painted edges from the reusable masks `img/magic-cats/edge-{1,2,3}.svg` and a small "living" overlay each; the overlay positions are hand-measured per picture in the `{% case %}` block of `books/magic-cats.html`, so re-measure them if an illustration's composition changes. The fixed treetop band at the bottom is the reading progress ("the delivery round": the cat hops on as you scroll, one house window lights per finished section). Pictures and paragraphs settle in once as they arrive (`.is-in`, set by an IntersectionObserver); a touch on a picture sends up a few chalk stars; every paragraph ends with a quiet "play this part" link to its scene (`/play?scene=N`). The "Lullaby" button in the top bar is off until asked for: it then loads the game's synthesiser (through `new Function('u', 'return import(u)')`, so the ES5 file still parses on old tablets), the tune and night sounds follow the section being read (`SONGS` map in the book script, with a 1.5 s dwell before a change) and each hop of the cat plays the next note; after 25 minutes the tune lets go by itself. The angel figure is multiplied into the page, so its chalk stars (`.mc-pop`) are appended to the spread, not the plate. The cats of the delivery round, the cat in the invitation window and the chalk cat at "The End" are the game's cats redrawn small by hand in the ES5 book script (the page does not load `cat.js`): when the game's cat design changes, redraw them here. The page turns pale for the angel when its section reaches mid-screen in two columns, but already when the picture rises to ~92 % of the screen height in the stacked layout, and the figure only shows on the pale page (it is multiplied, so on a dark page it would be a dark ghost). Everything animated stops under `prefers-reduced-motion`, the page prints as ink on paper (lazy pictures are switched to eager on `beforeprint`; break rules keep it to 11 pages), the top bar fits down to 320 px, and it reads fine without JS.

**The game** (`books/magic-cats-play.html`, standalone `layout: null`; `css/magic-cats-play.css`; ES modules in `js/magic-cats/`, no build step, no dependencies, nothing sampled — art is drawn on a canvas, sound is synthesised with WebAudio):

- `main.js` — shell: loop (`frame` → `tick(dt)`; a frame may be up to 0.12 s long so the story keeps real-time pace down to ~8 fps, and the scene update is sub-stepped so no step exceeds ~1/30 s), scene switching (`go(i)`; the curtain between two scenes shows the chapter card and, from chapter 2 on in manual play, a "Good night" button that returns to the title and dims it; a tap lifts the curtain once the card has been readable, and any switch asked for during a card goes straight there without building the chapter), HUD, hints (the hint pill can be tapped to perform the gesture, `doExpect()`; the hint stands aside while a gesture is performed for the player), a chalk ripple under every touch, save (`localStorage['magic-cats-play-v2']`: `reached`, `done`, `flies`, `sound`, `voice`, `tree`; sanitised and clamped in `loadSave`; chapter 9 counts as done when the end card appears, and the end card is modal: everything behind it is inert), `window.__mc` debug/test hooks. Scenes are loaded on demand from `scenes/<name>.js`; `SCENES` lists them (0 = title, 1–9 = the nine paragraphs of the book); any other `?scene=<name>` is loaded as a dev scene (the character lab, below). Robustness: a scene whose `run()` throws still counts as finished, and one whose `update()`/`draw()` throws every frame is let go of (`letGo`); `keepAwake()` holds a screen wake lock while the story plays itself; `doze()`/`rouse()` dim the picture and fade the music after 25 idle minutes of watching or 3 minutes on the end card (any touch wakes).
- `input.js` — pointer and keyboard. One pointer is followed at a time, but **a new finger takes over unless the first is busy** — it landed on the start of a hold or drag expectation, `holdOn` is holding or `dragTo` has grabbed (`scene._lasting`), or it moved more than 12 px in the last half second (a stroke, a pan) — so a thumb resting on the screen never blocks the other hand, and quick two-finger tapping loses nothing. On a take-over the scene sees `_up` of the old pointer (with its own id, at its last position) and then `_down` of the new one. A touch that is not busy and rests still for 3 s is let go of the same way (it ends as a tap there, so "watch the story" plays on under a resting thumb) and is ignored until it lifts — unless it then moves decidedly (> 24 px in half a second, in manual play), which makes it a new press. Escape always reaches the game (Space and Enter belong to a focused button). `main.js` `secondTouchClicks()` makes the `click` a browser does not make for a non-primary touch, so the page's buttons answer the other hand too.
- `scene.js` — `Scene` base class: `async run()` scripts on the scene clock (`wait`, `tween`, `until`, `spawn`), narration (`say(i)`, `tell(i)`, `next()`), awaited gestures (`tapOn`, `tapAny`, `holdOn`, `dragTo`), particles. Whatever the player is expected to do is exposed through `currentExpect()` — the same data drives the on-screen paw hint (keyed on gesture kind + text, so a drifting target keeps its hint rhythm), the Space key, **"watch the story"** (`Game.autoPlay`: the paw shows the gesture, then performs it; started with the title's "or simply watch the story" or the ▶ switch in the corner of every scene; a real touch takes over at once — `takeOver()` lets the performed drag or hold go first, then the finger's press reaches the scene — and whoever plays along gets more patience) and the automated play-through, so **every required interaction must be an expectation**. A drag expectation may carry `slow` (seconds the gesture should take when performed for the player) and `via(u)` (a path of its own, in world coordinates). Every gesture's hit radius is floored at ~26 screen px (`hitR`); `tapAny` targets may be live objects with getters, and `onDone(i)` lets an already-finished target still answer a touch. A scene's `onToy(p)` (Street: moon and town toys) returns true when it answered, and is also consulted while `next()` waits for "tap to go on".
- **The director's camera** (in `scene.js`, with `view.js`): scenes frame by *what should be in the picture*, not by camera coordinates. `shotFor(box, o)` → `{x, y, zoom}` for a world box (`{l, r, t, b}` or `{x, y, w, h}`) shown as large as possible in `freeRect()` (the screen minus top bar, caption and hint line); `shot(box, dur, o)` eases there and holds (re-framed on resize / rotation); `track(fn, o)` follows a box every frame with damping and a zoom dead zone; `wide()` hands the camera back; `directing` is true meanwhile. Options: `pad`, `min`/`max` (default max `ZOOM_MAX` = 1.8), `ground` (keep the ground line in place), `clampX`, `exact`. On short landscape screens every `max` above 1.2 is raised by `view.closeK` (sprite-safe, ≤ 2.4; `exact: true` opts out) so close-ups stay close on a phone held sideways. Each scene has one `frame()` that returns the box for the current phase. The rules every scene follows — most of them learned from the QA rounds of 2026-11-11:
  - an establishing shot first, then closer shots at the moments that matter; the hero is roughly 1.3–1.5× the old size, up to ~1.8× in close-ups;
  - **one stable box per beat or phase.** A box must not change when an expectation switches on or off (during a caption the next step of the road is still part of the box): otherwise the zoom "breathes", which `closeK` makes glaring on landscape. A walk is one fixed-size window that travels with the walker, as tall as the shot waiting at its end;
  - hold the camera still while something is dragged, held or drawn (the drop point must not slide under the finger), and **offer the next gesture only when its shot has arrived** (or the target is ≥ 30 px inside `freeRect()`), with a time limit so the story never waits for a camera;
  - everything that matters is **wholly in the picture or clearly out of it** — never cut in half by an edge, never under the caption, the hint line or the star bar (a waiting character's half face at the edge is a defect);
  - **nobody stands inside anybody.** Give characters that share a place their own spots (`seat()` in `kitten.js`), make the one who waits step back before the other arrives, keep one spacing rule for two who walk together, and never assign a position to a visible character without a movement to it (a follower overtaken by the leader's next leap is the classic case). The heroes are never hidden behind extras: extras stand in the back lane;
  - when a pose and a position change together, change them in the same tick (step the mover before the rig updates);
  - while a character is in the air frame where it lands; Street scenes set `skyFixed` (moon and clouds keep their screen size under zoom, `farK()`).
- `view.js` — camera (world y = 0 is the ground; a 640-unit-wide "safe box" is always visible clear of the caption at zoom 1). The caption lies along the bottom on wide screens and under the top bar on upright ones (`view.captionTop`, class `mcp-captop` on the stage; a scene without narration sets `view.plain`). Hang sky things from `view.free` (the top of the uncovered screen), not from `view.top`. `resize()` also sets the sprite resolution for the device (`paint.js` `setSpriteRes`: 2 px per unit on phones, 3 on tablets, up to 4 on retina desktops) so cached scenery stays crisp under zoom.
- `paint.js` — painting primitives in the book's look (wobbly outlines, crayon rings, chalk, sky palettes `SKIES`), plus: `wind(x, t)` — one breath for the whole world, used by grass, crowns, smoke, flags; `drawGround` / `drawGrassFront` (call the latter after whatever stands on the ground); `sprite()` cache; `tintSprite()` for flat shapes whose colour keeps changing — **never put a transitioning colour or a zoom into a sprite key** (a fade would cache hundreds of canvases; scale with the canvas transform instead); `Layer` / `drawSkyAll` — full-screen layers painted once into an offscreen canvas and then blitted: shifted while the camera pans or climbs, scaled while it zooms, repainted only when the picture no longer covers its part of the screen or its colours change. `Layer.off = true` paints afresh every frame — the pictures must then look the same.
- **Characters.** `actors.js` is only a hub re-exporting `cat.js`, `people.js`, `birds.js` and `bundle.js`; all three rigs draw with `rig.js` (`inked(parts)`: every shape of a group is stroked, then filled, so **one ink line runs round the union** — nothing looks assembled from parts; `blob`, `oval`, `limb`, `line`, `boil`, `ik2`, `within`). They share one idea: whatever a scene asks for only sets a **target pose**; the drawn pose follows on springs, so poses are moved into, never switched.
  - `cat.js` `Cat` (kinds `papa`, `kitten`, `mama`, `night` in `CAT_KINDS`; the kitten's proportions follow `c.head` / `c.leg` / `size`, which scene 3 grows): `mode` 'stand' | 'sit' | 'curl' | 'upright', `crouch`, `headDown` + `tongue` (lapping), `eyes`, `carry` / `bundleSize` (bundles hang from the mouth and swing), `glowing`, `light` (0 dark, wide pupils … 1 day), `look` (a world point: the **head** turns to it; idle head movements keep off while it is set), `walking`. The gait follows the distance actually travelled — move a cat by tweening `x` at a walking pace (≈ 55–70 units/s for Papa; faster becomes a trot, then a bound; the kitten scampers) and the paws stay planted; a jump of more than 60 units in one frame is a teleport and resets the gait. `leapTo()` gathers, launches, stretches and lands forepaws first (it returns the whole duration; wait with `until(() => !cat.jump)` or the `done` callback; from a sit or a curl the cat stands up first). `act(kind)`: look, ears, tilt, yawn, lick, stretch, slowblink, knead, pounce, bow. `anchor(name)` → world point (`mouth nose headTop head ear neck back chest pawFront hand tailTip`), `localAnchor(name)` → the same in the cat's own frame for things drawn after `cat.frame(ctx)` (the garden's scarves, bows, aprons — draw a cat's clothes together with that cat, or they paint over whoever stands in front). `sitting` (getter), `tailCurl`. Upright cats: `armUp` (a wave), `armHold` + `armReach` (a steady arm), `bindle`. When nothing is asked of a cat it fidgets by itself (`cat.fidget = false` to forbid) and, where a `Leap` is waiting for the player, sits down (`idleSit`). Call `cat.meow()` with every meow sound and `cat.wake()` before scripted business. `Cat.still` (reduced motion) switches fidgeting and the line boil off; `Cat.onAct` lets the shell give an act a voice. (`_px` is the previous x for the velocity and `_spx` the detail scale — one name for both once froze every moved cat's gait.)
  - `people.js` `Kid` (kinds in `KIDS`: five children, grandma `bun`, grandpa `cap`, `papa`, `mama`): `drawBust` (in a window; clipped by `House._window`) and `drawFull(ctx, t, part)` (`'body'` / `'arms'` for a two-pass figure with something between body and arms — the tree hug in `library.js` hides her far half with a clip of the trunk's own outline rather than painting bark over her); `mood` 'wait' | 'happy' | 'wave' | 'read' | 'sleep' | 'wistful' | 'wonder' (+ full figures 'hug', 'hold'); `pose` 'stand' | 'walk' | 'sit' | 'hang' | 'lie'; `look`, `turn`; `cheer()`; `act(kind)`: yawn, rubEyes, clap, nod, point, shrug, stretch; `anchor(name)` (`hand handL handR head headTop lap`); `carry(dx, dy)` tells a figure that what it stands on moved (a cloud, a sill) so that is not counted as steps; `wind = {x, y}` streams hair and pigtails (the rope rides). `drawHead(ctx, o)` paints just a head with the same faces and hair — `candle.js` uses it for the bedroom's Papa and child.
  - `birds.js` `Bird`: perch life (head snaps, preening, fluffing, hop-turns), `chirp()`, `peck`, `flyTo()` (take-off, swoop, flare, settle), `look(yaw, tilt)`; `drawButterfly`, `drawFirefly`.
  - **The character lab**: `?scene=lab` (index), `lab-cat`, `lab-people`, `lab-birds` (`scenes/lab*.js`; `&card=<name>`, `bg=`, `only=`, `kind=`…) show every pose as a *sheet* and every action as a deterministic *clip*. Look at a character there before and after changing a rig.
- `street.js` — `Street`: base for town scenes (time-of-day sky, far roofs with lit windows, trees, houses, cats, small ambient life, a ticklish moon via `skyToy`; cats, birds and loose bundles far outside the view are not drawn). `deliver(cat, house, win)` is the story's central gesture and a small piece of acting (≈ 1.4 s: the cat turns to the child, the bundle floats in an arc from its mouth into the child's hand, the child cheers, the cat squints with pleasure; the window's rings bloom and then relax to 0.55 unless the scene writes `rings` itself) — frame it so the child's half can be seen (a long `ledge` on the window, the cat standing clear of it). `watchCats()` makes children in lit windows follow the nearest cat by themselves; a `look` set by a scene always wins. `leap.js` — treetop leaping (`Perch`, `Leap`; `reach(perch, {past})` also accepts perches further along the road, so a quick child is never sent back; `pick(p)` counts a touch for a perch only inside a generous ellipse round it — anything else is a friendly "mrrp", so a stray tap in the sky never sends the cat backwards); while the player aims the cat looks at the perch, followers watch the leader, petting is a purring squint. `props.js` — trees, houses (doors and window boxes are placed automatically; pass `door: false` to forbid one), candle, saucer…; `story.js` — captions, UI strings, and the opt-in read-aloud voice (Web Speech API; the button on the caption appears only if the device has a voice for the language).
- `audio.js` — generative 6/8 lullaby engine (`SONGS`, one chord table per mode, counter-melody and fills), ambiences (`night`, `day`, `dusk`, `water`, `sky`, `rain`, `room`, `dream`), effects in `sfx.*` (besides the obvious: `shimmer`, `twinkle`, `goodnight`, `paper`, `flutter`, `yawn`, `owl`, `cuckoo`), `duck()` while the voice reads. The engine remembers whether sound is *wanted* and resumes from any non-running state (iOS's `interrupted` included; a resume that arrives while a suspend is still pending is not lost), asks for `navigator.audioSession.type = 'playback'` (so the iPhone's silent switch does not mute it — unverified on a real device), and is parked while the sound is off; voices build nodes only while `live`. It also renders on an `OfflineAudioContext`, which is how levels and harmony were checked. **Nobody has listened to it yet**: change it only for robustness until Roman has.
- Scenes: `title`, `candle`, `treetops`, `kitten` (17 gestures), `moonmilk` (saucer drops are forgiving: near a free place they glide there, otherwise home; each carry job starts with its longest drag so the whole task is seen first), `library`, `noticing`, `towers`, `clouds` (the look-around counts screen pixels, so one swipe is enough at any zoom), `garden` (+ helpers `garden-art.js`, `garden-tree.js`; a drawn stroke belongs to the pointer that began it, and the paw takes the drawing over only after ~25 s). The finale in `garden.js` reuses the scene-1 room via `new Candle(game, 1, {passive: true})` and a few of its coordinates (the sill, the flame at `CX, CY`, Papa's head) and public fields (`room.ch`, `room.pa`), so change `candle.js` with `garden.js` open. The tree the player draws is saved as `save.tree`, redrawn with `DreamTree` from `garden-tree.js`, and afterwards stands on the title screen.
- A scene shows every beat of its paragraph in order with `say(i)`; hint texts are `{en, de, ru}` objects next to the scene code; interface strings live in `story.js` (`UI`) and in the page's `lang` spans.
- URL helpers: `?scene=<n|name>` starts at a scene, `?fast` skips reading delays, `?speed=2` speeds up time, `?lang=`, `?watch` (offers watching first; the book's "or watch it play" link uses it). Scene 9 also takes `&at=pick|tend|draw|finale|town|room`.
- Verify changes by playing, and by looking: the test tools live in local-only `book_cats/tools/` (README there; `verify-all.sh` runs the whole matrix). The game is driven with real pointer input from `__mc.state().expect` at 1280×800, 390×844 and 844×390 in all three languages (`tour.js`), by letting it play itself (`watch.js`), with the Space key (`keys.js`), with a hesitant player who waits before every gesture (`qa-hesitant.js` — the cats' idle life only shows then) and under reduced motion; `pops.js` reports teleports and "snaps" (a cat put somewhere without a movement; `MC_WATCH=1` is where they show), `cam-measure.js` the hero's size on screen and the zoom over time, `lab.js` captures lab sheets and filmstrips, `MC_ENGINE=webkit|firefox` runs the same tools in Playwright's WebKit and Firefox. For looking at motion, `__mc.manual(true)` stops the clock and `__mc.step(dt, n)` advances it — one tick per call when a scene script must run in between, on full-screen frames (a crop that follows a character hides its jumps), and enlarge crops 3× to judge an edge. The social card `img/magic-cats/play-card.jpg` (1200×630) is a screenshot of the finished title screen without the chrome (`card.js`).
